# ¡Hola, somos BBDD-InfoWeb!

Nuestro proyecto consiste en crear un recurso interactivo y didáctico sobre **Normalización de bases de datos**.

La idea es diseñar una página web clara, atractiva y fácil de entender, que explique qué es la normalización, sus formas normales, beneficios y casos de uso, usando ejemplos visuales y explicaciones sencillas para facilitar el aprendizaje.

Vamos a seguir la metodología SCRUM, usando tableros en GitProyects, sprints, historias de usuario, reuniones de retrospectiva y planificación.

Documentaremos todo el proceso, y en Git emplearemos ramas y commits claros  para colaborar eficazmente.

La entrega final será un recurso web funcional que enseñe la normalización y un video explicativo de 5 a 10 minutos donde mostraremos cómo funciona nuestro recurso, una breve explicación del tema, ejemplos en vivo, cómo aplicamos SCRUM y buenas prácticas en Git.

El repositorio debe incluir un README bien estructurado con:
- El nombre del proyecto y el tema.
- Una descripción general del recurso.
- Instrucciones de instalación y uso.
- Créditos del equipo (nombres y roles).
- Evidencias del uso de SCRUM (capturas del tablero, historias, sprints).
- Evidencias del trabajo en equipo en Git (ramas, commits, pull requests).
- Enlace o archivos del video explicativo.

Debemos asegurarnos de que el recurso sea fácil de ejecutar, con estructura clara y ejemplos visuales que muestren diferentes niveles de normalización.
