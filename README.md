# 📡 InfoWeb:

**🌐 Descubre cómo funciona el Internet, las API y los protocolos que conectan el mundo digital... ¡explicado por y para estudiantes!**

> 🛠️ *Este proyecto se encuentra en desarrollo; se espera ampliarlo a una Web Completa no exclusiva a BBDD*

**BBDD-InfoWeb** es una aplicación web didáctica construida por estudiantes, con el objetivo de explicar de forma clara, visual y atractiva conceptos esenciales del mundo digital, como _qué es el Internet_, _cómo funcionan las API_, y _cuáles son los protocolos que permiten la comunicación web_, como _HTTP_ y TCP/IP.

Está diseñado para ser un recurso accesible tanto para principiantes curiosos como para estudiantes en formación técnica. El proyecto permite navegar entre secciones informativas, ejemplos interactivos y visualizaciones de flujos de datos.

¡Nuestro propósito es compartir conocimiento de forma creativa, divertida y útil para cualquiera que quiera entender mejor la magia que ocurre cada vez que se conecta a Internet!

---

## 🧠 ¿Qué puedes aprender aquí?

- 🌐 Qué es Internet y cómo se conecta todo.
- 🧪 Qué es una API y cómo se comunican con las apps modernas.
- ⚙️ Cómo funcionan los protocolos HTTP y TCP/IP.
- 🔄 Ejemplos de peticiones y respuestas entre clientes y servidores.
- 💬 Foro interactivo para recibir explicaciones de nuestra comunidad.
